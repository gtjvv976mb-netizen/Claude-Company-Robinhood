# What the Solana desk cost us, and what this one does about it

Mined on 2026-09-04 from the Claude Company codebase's own comments, its git history and the
owner's notes across projects: **176 lessons, 176 distinct after merging**. Sorted by what
each one cost.

The point of this file is the first table, not the list. A lesson that depends on being
remembered will be forgotten — so the ones that could be made mechanical were, and the rest are
marked honestly as things a person still has to hold.

## Enforced by code

| lesson | enforced by |
|---|---|

Each lint rule is tested against the code that actually failed on Solana **and** against the
actual fix, so it catches the real shape rather than an invented one. `assertLiveReady()` refuses
to arm the executor while any live-path threshold still carries a Solana measurement.
